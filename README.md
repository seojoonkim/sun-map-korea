# SUN MAP KOREA

강남구의 날짜·시간별 태양 위치와 일조 환경을 탐색하는 인터랙티브 웹 프로토타입입니다. Next.js App Router, TypeScript, MapLibre GL JS로 구현되며 외부 API 키가 필요하지 않습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증 및 프로덕션 빌드

```bash
npm test
npm run lint
npm run build
npm start
```

## 구현 범위

- 강남구 경계 인근으로 탐색 범위 제한
- OpenStreetMap 래스터 기반 실제 도로·건물 맥락
- 강남역, COEX, 선정릉, 도산공원 프리셋
- 오늘/춘분/하지/추분/동지 및 직접 날짜 선택
- 시간 슬라이더, 자동 재생, 방위각·고도각 표시
- 선택 장소별 일출·일몰·낮 길이와 휴리스틱 일조 지수
- 태양 반대 방향의 시각적 그림자 fan 시뮬레이션
- 데스크톱/모바일 반응형 UI

## 데이터 및 한계

- 태양 방위각·고도각과 일출·일몰은 `SunCalc`의 좌표·시각 기반 천문 계산입니다.
- 일조 지수와 예상 일조 시간은 제품 경험을 위한 고정 휴리스틱이며 현장 측정값이 아닙니다.
- 그림자 fan은 선택 지점과 태양 각도로 만든 방향성 시각화입니다. 개별 건물 형상, 정확한 높이, 지형, 수목, 기상, 반사광을 계산하지 않습니다.
- OpenStreetMap 공개 래스터 타일은 API 키 없이 사용하지만 네트워크 및 공개 서비스 가용성에 의존합니다.
- 부동산, 건축, 건강 또는 법적 의사결정에는 사용할 수 없습니다. 정밀 일조 분석에는 공인 측량 데이터와 전문 시뮬레이션이 필요합니다.
